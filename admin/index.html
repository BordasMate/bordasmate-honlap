GitHub-kapcsolat

A Közzététel gomb a content.json fájlt írja a GitHub-tárolóba; a Netlify ezt észleli, és kb. egy percen belül frissíti a honlapot.

Hogyan kapok tokent?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories, és válaszd ki a honlap tárolóját.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Másold ide a kapott tokent. Csak ebben a böngészőben tárolódik, a honlapra nem kerül fel.
